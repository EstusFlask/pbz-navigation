# 1.2.2 现场问题修复（本地测试候选）

日期：2026-11-13，America/Tijuana。基于用户使用1.2.1时的四段实走、导航日志与角色只读采样。本版修改导航本体，未把四条轨迹添加为固定课程，没有恢复玩家通路学习。游戏内复测待用户有空后进行。

## 已复现并修改

### 绕行连接成功，剩余后段失败时过早结束

现场记录有`local detour result: checked connector`之后`local detour validation: surface is not walkable`的序列。最小控制流回归用两处有限障碍重现：任一障碍单独存在均能通过，同时存在时第一次绕行接在第二处障碍之前，整段复验失败后立即返回。

`PBZRouteRepair`现在在同一个截止时间内继续尝试剩余的4/8/14米接回点。完整复验通过才作为成功路线；全部失败或预算结束时保留已检查较长前段的拒绝结果，供调用方继续诊断。碰撞、门锁、动作边界与原3500毫秒总修补预算保留。

### 攀爬后的高层目标禁用了局部楼梯连接

上塔记录中的攀爬之后，还有约24.8米高度的普通步行上楼段。动作链规划原先对所有高差超过2米的目标连接设置`local:false`，包括已经完成合法动作之后的目标，导致已有的局部楼梯搜索不能运行。

`PBZRouteTransitions`现在允许已验证动作之后的目标使用原有局部步行连接，缓存也区分这种搜索权限。直接从起点到高层目标的原策略保留。实际连接仍由`Passages`限制在45米内，垂直情形最多1800节点、2400毫秒单次执行预算，并遵守整条动作搜索的截止时间；每步仍检查地面与身体空间。

回归使用真实攀爬边界、17个动作样本和385个上层行走点，场景导航和碰撞以测试替身代替。它验证调用方不再禁用可用连接，不能证明本版已经在真实楼梯上走通。

### 角色有效地面与零距离步行验证不一致

原地连接仍会重新扫线，可能在`CharacterMovement.CurrentFloor`已经确认有效时报告无地面。`PBZRouteWorld.step`现在对小于0.1厘米的零距离连接复用当前已占据脚点的有效地面接触。相邻步伐、其他楼层、悬空状态仍使用原检查；没有扩大支撑范围或放宽真实移动的碰撞规则。
