# 1.8.3：小黑盒归档与原数据来源恢复

日期：2026-11-15（America/Tijuana）。本次“恢复原版”按撤下小黑盒接入处理，恢复原有地图数据与寻路来源，保留之前已做的导航、手柄、补采和碰撞修复。没有把整个 Fork 降回上游 0.8.5-beta。

## 已移除的运行内容

- 小黑盒生成的 `PBZRouteMapData` 全部候选分块与 `PBZRouteMapHints` 读取器。
- `PBZQuestRoute.tick` 的世界索引／页面预热。
- `PBZRouteWalkHints` 的模型包装层、候选混合与模型世界支持判断。
- `LocalWalk` 和 `HintWalk` 的模型专属回退、异步页面等待、共享100毫秒预算和失败连接去重，以及主规划器／修补器／动作连接中的预算传递。
- 安装包中的小黑盒接入说明、模型数据摘要字段；小黑盒专属测试和离线工具移入归档。

`PBZRouteWalkHints` 恢复为原有已审核脚点索引，其他世界返回无此辅助数据，继续通过原离线路网、UE原生查询和有限现场搜索规划。正向搜索、单向动作、实际地面／胶囊碰撞／锁路检查、收集物联动、补采、原有路线修复保持。没有重新引入已删除的反向搜索。

## 保存在哪里

素材、读取与生成工具、测试、审计、接入文档和移除前代码快照，集中在 [archive/heybox-20261115](../archive/heybox-20261115/README.md)。原始源包和解码器的本地副本、解包观察与缓存放在该目录忽略提交的 `local/` 下，清单记录源包SHA256。应用安装目录中的原文件保持原位。

独立实验分支 `codex/heybox-navigation` 保留为历史。旧1.8.2完整安装包保存至 `build/release-archive/pre-1.8.3-20261115/`，当前 `dist/` 只交付1.8.3标准／开发包。

## 验证边界

构建器只收集 `Quest_Navigation/` 和明确列出的文档；包验证额外拒绝已归档模型模块、数据目录、接入文档与摘要字段。执行结果见 `release/VALIDATION-1.8.3.txt` 和 `release/LOCAL-CANDIDATE-1.8.3.json`。

本次没有改游戏安装、管理器登记或玩家存档，没有上传。既有现场记录继续保留原版本和范围；1号路线仍只确认最后一次F之后的后段，不能把本次撤回记为全程修好。移除数据来源不能证明所有撞墙会消失。

导航原理、撞墙证据与官方／开源方法的采用情况见 [说明与研究](NAVIGATION-EXPLANATION-20261115.md)。
