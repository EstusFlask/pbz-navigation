## 格式与读取

所有原Detour字节、packet编号/parts、门状态变体、页内容、走廊和子网格均保留，未重烘焙。每32KiB独立raw DEFLATE，多个压缩Base64块进入不超过1MiB的ASCII容器；512条一页的目录保存范围、原长度与CRC。代码不通过CommonJS加载数据，不依赖Node、DOM、Worker或WASM生成。运行时最多缓存2个容器、4个目录页，原packet、tile和窗口预算保持。

初版fflate小push流式解压反复拷贝32KiB历史，解释压力控制触发30秒期限。最终使用锁定fflate0.8.2的固定输出版本：stored、literal、match三条写路径均在写入前检查硬上限，且检查流实际消耗长度；源码与来源hash在`offline-navigation/vendor/`，MIT许可随Mod。CRC和UTF-8转换分片。50ms慢步、30秒总期限未放宽。
