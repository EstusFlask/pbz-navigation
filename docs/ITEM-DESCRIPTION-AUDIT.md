本版沿用 0.15.0 的描述审计与 170 条补充数据；两版真实 Lua 描述显示回归重新通过，本次未新增或重写描述。

1,391 项中包含大量游民未单独标出的普通材料、消耗品和无具体物品身份的货币点，不表示游民有 1,391 条可直接补入的攻略。另外逐项登记 530 条 nativeDetails：它们仅提供区域、类别和坐标，缺乏可核实的物品身份，未凭坐标强行配说明；同位目录项能使用补充后的 source 数据。

匹配要求同地图与官方中文名称。装备 ID 先经原 Mod 的 nameKeys/fallbacks 解析；重名项再使用分组地图投影，要求足够接近且明显优于其他同名实例。投影只用于辨认地图标记，不作为三维路线或可通行证据。不同地图、场景副本或高度不会因为名字相同就合并。

170 个目录点的提示逐条改写为简短地点/操作/用途事实。示例：鸽饲料原本只有“开启宝箱”；现在提示先取得虎炮，回悲泣溪谷龙柱西南山洞破墙后开箱，材料用于长柄金瓜。还包括需锁镰的营地钥匙、巨凶斧断链、长柄金瓜破地板、幻术琵琶和烈焰狮头等条件。只有攻略提到的条件才写入；提示不代表游戏当前已解锁。

运行时由导航自己的 PBZQuestRouteCompat 载入 PBZItemHints/PBZItemHintsData，补入同 VM 的纯数据目录，不改写 PbzMapTracker 安装文件。需同时满足 saveId、物品键、位置及原通用提示，防止后续版本 ID 复用或覆盖作者新增说明。只改简体中文 sourceHint，其他语言和收集逻辑保留；重复安装不叠加，停止适配时恢复原值。该功能需要兼容的 UE4SS 及收集 Mod。

本地验证使用 1.0.9、1.0.14 的真实 Lua 字节码，经过 CollectibleCompose 和 NativePresentation.describe，确认鸽饲料实际提示含虎炮要求，英文显示保留；另检查全部 170 条补入、重复安装、版本内容变化和清理。没有进行本版游戏界面实测。

来源定位：游民路书 53；八图 `getLandmarkList` 公开接口。每条补充数据保留 sources 标记 ID，例如鸽饲料 914439、营地钥匙 912270。原始 HTML、图片、完整攻略/API 数据与游戏目录导出仅留在忽略的 build/，不随安装包分发。

复核命令：`py -3.12 -X utf8 tools/audit-tracker-descriptions.py`（使用临时测试依赖 lupa.lua54、numpy、scipy）；运行时无需 Python、下载或联网。
