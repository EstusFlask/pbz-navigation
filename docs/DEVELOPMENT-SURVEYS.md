# 开发版地图补采 · 1.11.5

日期：2026-11-15（America/Tijuana）。补采点接入Map Collectible Tracker **1.0.14**的真实目录、仓库、物品提示和选择服务，共47段、94个开始/结束物品。此前1.7.0自绘方案在游戏里无法正常选中和显示名称，现已移除。按用户要求停止维护1.0.9，参考副本及自动从Git恢复的代码已删除；历史记录保留。

## 操作

1. 退出游戏，解压`Quest_and_Exploration_Navigation_Fork_1.11.5_Development.zip`，用UE Mod Manager导入同时包含`ProjectPBZ`与`platform`的解压目录，完整替换导航后重启。现有Map Collectible Tracker1.0.14、UE4SS及玩家设置保留；两种导航包只启用一份。文件名没有`Development`的是发行版，不显示补采点，也不记录采集按键。
2. 地图补采现在通过收集Mod呈现。开启其“任务物品”相关筛选或显示全部，沿用该Mod的图标和物品详情面板。开始点为绿色、结束点为橙色；完整名称为“1号路线开始／1号路线结束”。详情显示地标、采集目的和操作说明。
3. 使用收集Mod原有方式选择、追踪物品；鼠标左键选中追踪，也可悬停后中键导航。导航手柄十字键可在真实标记间移动，A确认。终点保持原始XYZ和世界，不按附近路网改写。
4. 先选择本次编号的开始或结束物品。到对应开始点附近落地，**轻攻击一次开始记录**；到同编号结束点附近落地，**轻攻击一次结束并保存**。仅靠近、停留、打开地图或选中物品不会开录/结束。一个地点有多条路线时，先明确选择编号。
5. 导航错误时**重攻击标记**；自己走错时**防御标记**。防御记录是独立的个人误走候选，保留原轨迹，分析核对后再排除误走区间。
6. 看到“已结束并保存”后告诉助手编号即可。采完的路线按本地进度交给收集Mod标为已采集，并在其后续刷新中隐藏；重启保留进度。

默认键：轻攻击手柄X／鼠标左键；重攻击手柄Y／键盘F（保留旧键盘Y标记键）；防御LB／鼠标右键。当前监听默认键，不自动跟随改键。地图/菜单不触发采集，按住不重复，不发送或拦截游戏输入。录制中换定位目标不会停止记录。

## 路线与范围

任务仍为47段，溪谷6段；编号和原有采集记录保留。溪谷2号恶弓手营地→塔一层，3号远眺龙柱处→瀑布吊桥，4号吊桥→塔底，12号圣母像裂缝→初见玉儿处（锁链），13号红丝线障壁→残偶谷底（影武装），14号塔一层→血肉花田。其他区域含火狮影武装、钩索、滑索、升降梯、眼部机关、面具条件和锁门等。

任务表见`authoring/development-survey-plan.json`，通过`node tools/build-survey-catalog.cjs`同时生成JS任务与导航自有Lua物品目录。区分补连续几何与验证现有候选；路书提示仍须现场核对。已经采过的A-01—A-04不重复编入；身份/端点未解、跨world未绑定、极端高度副本和剧情传送继续留待专项处理。

全解锁档中已开启的机关只能证明当前通行；开启前、缺武装、未装备和剧情限制仍须相应状态另测。47是任务数，不是已验收道路数。

## 实现与数据

导航自己的UE4SS宿主在收集Mod VM启动阶段扩展内存目录，不替换`PbzMapTracker`文件，不添加实际背包物品、不修改游戏存档。使用其真实Compose→Repository→NativePresentation→Selection链路；补采名称仅对自有saveId生效，普通物品名称和提示保持原逻辑。只以1.0.14为维护参考。

JS和Lua都有由打包器写入的固定flavor标记。标准包不加载补采目录，即使手动合并更新留下开发文件也不会启用；开发包中的六个开发模块包括四个JS模块、两个Lua目录模块。旧自绘地图模块不再打包。

保存与1.7.0一致：10Hz整段采样，每5秒分块，起终点按450厘米水平/150厘米高差和实际地面检查后由轻攻击确认。保留地面、移动状态、可取得的锁状态、规划和动作连接、碰撞、蓝线快照及重攻击/防御案例。已查询锁的缺席不证明解锁或装备。

Saved中的`PBZQuestRoute-survey-*.json`为清单、`PBZQuestRoute-surveydata-*.json`为分块、`PBZQuestRoute-dev-*.json`为类型化问题/误走案例。进度文件`PBZQuestRoute-surveys.json`支持引擎UTF-16；收集端只读，按完成卡的revision更新自身标记状态。

切图、上下文变化、超过1秒断档、大位置跳变、移动停用和已识别车辆会中断保存，不拼成道路。单段20分钟/240块、会话20次/6400万序列化字符、每文件250万字符和100份案例上限不变。写后读回失败不计完成；意外退出可能缺最后5秒。没有网络或自动道路学习。

完成后助手运行`py -3.12 tools/import-development-cases.py`，原字节与SHA256复制到`build/development-cases/`。报告分别列出导航问题与个人误走，并对照实际轨迹、规划与蓝线；修复后从原起点复测，采完和导航通过分别记账。
