自1.11.4起，每个新版本必须同时生成标准包和`Development`开发包，并用`tests/verify-package.py --flavor all`核验。两者共用导航核心、相同安装标识且互相替换。标准包为发布用包，排除开发采集模块；开发包在本地测试分发，不随标准包自动公开上传。`dist/`仅保留当前版本的这两个包，旧版本各包归档并记录SHA256。同版两包的行为边界分别核验。

1. 同步版本号，生成并校验完整ZIP，再上传当前Nexus页面。
   上传成功后到公开页核对页面版本、每个文件的实际显示简介和对应的 changelog。双版本发布时还应核对 Mod 正文的版本选择和切换说明。保存发布回执，不持续监控 Nexus 病毒扫描。
2. 普通修复和优化只写changelog；新增按键、设置或不容易发现的用法，才补充description。
3. 文件说明与更新说明面向玩家，简短、中英各一句，说明实际功能和变化。不写“仍需实测”“部分路线仍需测试”等工程性表述；测试数量、验证状态、算法和排错过程留在开发文档。
   同样检查历史版本与累计changelog，移除测试统计、诊断日志、开发预算和发布操作记录，只保留玩家能感知的功能与修复。
4. 不把尚未完成的实测写成“全部修复”。发布后核对版本、文件和changelog，并保存发布记录。

格式：

### Version 1.2.10

- Improved stair and multi-floor navigation.
- 改善楼梯和上下层导航。
